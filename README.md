# Emotion Detector

Final project: AI-based web application that detects emotions in user-provided text using the Watson NLP EmotionPredict service.

## Features
- Watson NLP emotion detection
- Formatted emotion scores and dominant emotion
- Python package structure
- Unit tests
- Flask web deployment
- Blank-input and HTTP 400 error handling
- Static code analysis-ready Python files

## Run
```bash
pip install -r requirements.txt
python server.py
```

Open `http://localhost:5000`.
